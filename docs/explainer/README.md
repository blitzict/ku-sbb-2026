# Explainer

Material prepared for the finalist presentation and its Q&A.

| File | What it is |
|---|---|
| [glossary.html](glossary.html) | Every term used in the slides and code, in plain words. Open in a browser |
| [qa_prep.html](qa_prep.html) | The Q&A prep sheet: key numbers, slide-by-slide notes, likely and hard questions |
| [feature_demo.py](feature_demo.py) | Simplified versions of try4's main features, computed on the raw series so the idea can be read in one file |
| [data_format_example.png](data_format_example.png) | Picture of the input format: one row per point (`id`, `time`, `value`, `period`) |

`feature_demo.py` reads `data/train_series.parquet` and `data/train_labels.csv`, so run it from the folder that holds `data/`.

The two narrated technical explainer videos are attached to the [`v1.0-first-place` release](https://github.com/blitzict/ku-sbb-2026/releases/tag/v1.0-first-place).
