Known-boundary structural break detection

What changes when a series breaks?

For each series, the boundary is supplied. The model estimates whether the process that produced the observations changed there. Its most useful early discovery was a rhythm that changed phase even when the average and spread looked stable.

01 / Observations

What the detectors measure

Training used 24,000 labelled competition series, split evenly between breaks and controls. Each row of the final model represents one whole series. Earlier models saw the observations, statistics calculated on either side of the boundary, and differences between those statistics.

Feature familyMeasurement and purpose
Level, scale and shapeSegment lengths, means, medians, variances, quantiles, skewness and tails. Distribution tests and successive-value histograms detect a shape change even when mean and variance agree.
OscillationFit sine and cosine terms across trial frequencies. Compare a wave continuing across the boundary with a new amplitude, phase or frequency. Run the sequence networks again on the observations left after removing the fitted wave. A shift from peaks to troughs can be strong evidence even when both halves have the same period.
Serial dependenceAutocorrelations, fitted autoregressive coefficients, memory length and random-walk evidence. The prediction error after accounting for previous observations is called an innovation. Detectors compare its level, scale and distribution before and after the boundary.
Trend and transient pulsesCompare a lasting step with a continuing slope or curved trend. Estimate the amplitude, width and location of a short bell-shaped pulse near the boundary. Such pulses occurred in both classes, so their presence alone was a poor reason to call a break.
Volatility and shocksEstimate whether large innovations cluster, how persistent their effect is and how the quantiles of the next innovation change after a large move. A change in clustering can leave the overall variance nearly constant.
Two-peaked noise and orderEstimate the centers, widths, spacing and occupancy of two common levels. Sequence models examine both which level is visited and the movement around it. Additional detectors compare the order of signed and absolute movements, and joint ranks of observations 1, 3, 8 or 16 steps apart.

Likelihood-based detectors compare a shared process across the boundary with alternatives that allow one or more parameters to change. Trees learn interactions among these measurements. Convolutional sequence networks and multilayer perceptrons contribute separate scores. Full series, reversed or sign-flipped views, and real crops supplied different views of the same source. Crop-aware models kept views of one source together in their training splits.

03 / Training

The 152 weights the CPU learns

The CPU trainer starts with each series’ parent score in log-odds. It learns an additive correction from detector outputs. The feature builder first puts detector scores on comparable scales using training-fold quantiles, centers them at similar parent scores, and computes principal components within each family. This lets many similar models contribute one shared vote while retaining disagreements.

The optimizer starts every coefficient at zero. For each positive example it samples 32 negatives within 1.35 parent log-odds using seed 1729. Closer pairs receive more weight. The objective combines individual logistic loss (0.47), weighted pairwise logistic loss (pair mass normalized to 0.53 times the training count, temperature 0.55), and a squared-weight penalty of 84. L-BFGS-B fits the coefficients. Applying half the fitted correction limits the size of the edit.

break_probability = sigmoid(parent_log_odds + features @ final_weights)

05 / Reproduction

Run the exact CPU refit

From this folder, keep train.py beside training_inputs.npz (166.5 MiB). The pack contains the original labels, IDs, train/validation indices, parent log-odds and fold-specific feature matrices. The earlier models’ training is preserved in their archived predictions. The portable run trains the final layer afresh. It needs one CPU thread and no network connection once the dependencies are installed.

python -m pip install -r requirements.txt
python train.py

With the existing project environment on Windows, run this from the project root:

.\.venv-xpu\Scripts\python.exe .\cpu_0879\train.py

run/submission.csv contains id,break_probability. run/fit.npz contains the 152 learned coefficients, the 24,000 training IDs and held-out logits, and their pooled AUC. The CPU refit reproduced every coefficient and held-out logit exactly in the tested Windows environment. Its submission was byte-identical to the confirmed CSV.

06 / From the original data

Rebuild and train on CPU

The second path starts with train_series.parquet, train_labels.csv, test_series.parquet and sample_submission.csv. It builds 361 measurements per series and trains a LightGBM classifier. Its measured pooled five-fold ROC-AUC is 0.86523822. The complete run took 168 seconds with four CPU workers on this machine. The exact ensemble refit above reproduces 0.87911421 using the saved upstream detector outputs.

The feature builder reuses numerical detector functions from experiments/weight_space. Keep this folder inside the project when running it. It reads the four original data files and calculates the measurements afresh. All feature fitting occurs within one series. The binary training labels enter only when the five tree models and full-data tree are fitted.

Measurements cover harmonic phase and frequency changes, removal of periodic components, autoregressive and random-walk evidence, robust linear and curved trends, trend clock resets, short pulses, volatility-adjusted innovations and multiresolution rank partitions. A compact density grid compares shared and changed location, spread and noise shape under Gaussian, Student, contaminated Gaussian and two-peak laws. Those density comparisons run on the observations, corrected observations and innovations.

The tree settings are fixed across folds and the final fit. They use 720 trees, learning rate 0.025, 27 leaves, at least 58 observations per leaf, L2 penalty 6, feature sampling fraction 0.62 and 127 histogram bins. Five stratified folds use seed 7 and the official label-file row order. Each original series receives one held-out prediction.

python -m pip install -r cpu_0879/requirements_raw.txt
python cpu_0879/train_raw.py --workers 4

Use the project root as the working directory. The existing Windows environment can run the script with .\.venv-xpu\Scripts\python.exe .\cpu_0879\train_raw.py --workers 4. The script explicitly selects CPU training. Use --workers 1 for a single process, --data to point to the competition files, and --out-dir to choose the output folder.
