Reproducibility

Rerun it from the raw files with 3 commands

# 1 raw files → the 35 measurement tables and the noise priors

python try4/build_features.py --data data --work try4_run --workers 4

# 2 train and save the 15 models (3 models × 5 rounds)

python try4/train.py --work try4_run --out try4/model

# 3 score new series → submission.csv

python try4/predict.py --series data/test_series.parquet --ref try4_run --out predict_try4 --csv submission.csv --workers 2

data/ must hold the 4 competition files (train_series.parquet, test_series.parquet, train_labels.csv, sample_submission.csv). They are not in the repo because the data is not mine to publish. Setup: pip install -r requirements-cpu-full.txt with Python 3.12+. train.py fits XGBoost with device=cuda; on a machine without an NVIDIA GPU, change it to cpu. The trimmed feature steps can be switched off with KU_TRY4_NO_SLIM=1 to check that they give identical values. The evidence scripts behind these slides are in extra/slides/evidence.
