# Slides

The presentation deck: try1 to try4, why try3 (the full model) could not meet the inference limit, and how try4 was cut down to fit it.

- [slides.pdf](slides.pdf): the 26 slides as a PDF (static; no animations).
- `deck.json` and `slides/*.html`: the slide sources (one `<section>` per slide, 1920×1080, with speaker notes in each `<aside>`). Animated elements carry `data-build-in`, and slides use `data-transition="magic"` so the progress bar, page number and signal mark glide between slides.

- [evidence/](evidence/README.md): the scripts and result files behind every number on the "Test results" slides.
